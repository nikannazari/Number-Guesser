# Random Number Guesser

This is a simple random number guesser game.

## How to play

1. Run the program
2. Enter a number between 1 and 100
3. The program will tell you if you guessed too high or too low
4. You can keep guessing until you get the number right

## How to run
```bash
python random_number_guesser.py
```

## How to install
```bash
pip install random_number_guesser
```

## How to uninstall
```bash
pip uninstall random_number_guesser
```
